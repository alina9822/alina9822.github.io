**Technology & Tools:** Java, Cisco Packet Tracer, NS3

A set of five networking labs covering socket programming, concurrency, file transfer, simulation, and reliable data transmission.

## Key Work

- **Socket Programming Fundamentals** (`IntroductorySocketCodes`) — basic client-server communication using Java sockets, covering connection setup, data exchange, and message handling.
- **Multi-Client Server** (`IntroductorySocketCodes`) — threaded server design to handle multiple clients simultaneously, including a time server and concurrent request handling.
- **FTP-Style File Transfer** (`Offline1`) — server and client logic for user connections, requests, and shared file handling.
- **Network Simulation with ns-3** (`NS3-Assignments`) — simulated wireless/mobile networking scenarios, analyzing behavior across varying node counts, flows, packets, and mobility parameters.
- **Error Detection & Correction** (`Offline4`) — CRC and Hamming code implementations for reliable data transmission.

> The lab combines practical networking concepts:
> - TCP socket communication
> - Concurrency in servers
> - File transfer protocols
> - Network simulation analysis
> - Error control techniques
